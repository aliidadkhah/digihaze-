# ابرفروش — نسخه‌ی Next.js (سئوشده)

این پروژه نسخه‌ی مهاجرت‌یافته‌ی فروشگاه از یک اپ تک‌صفحه‌ای React (SPA) به **Next.js 14 (App Router)** هست. تفاوت اصلی برای سئو: صفحات حالا از سمت سرور رندر می‌شن (SSR/SSG)، یعنی گوگل محتوای واقعی صفحه رو می‌بینه، نه یک صفحه‌ی خالی که با جاوااسکریپت پر می‌شه.

## چیزهایی که برای سئو اضافه شده

- **هر محصول متای اختصاصی داره** (`app/product/[id]/page.jsx`): عنوان، توضیحات و تصویر og هرکدوم جدا تولید می‌شن، نه یک متای عمومی برای کل سایت.
- **داده‌ی ساختاریافته (JSON-LD)** روی صفحه‌ی محصول، تا گوگل بتونه قیمت و امتیاز رو مستقیم توی نتایج جستجو نشون بده (Rich Result).
- **`sitemap.xml` خودکار** (`app/sitemap.js`) شامل همه‌ی صفحات ثابت + همه‌ی محصولات.
- **`robots.txt` خودکار** (`app/robots.js`) که مسیرهای شخصی (سبد خرید، ورود) رو از ایندکس مستثنی می‌کنه.
- **`generateStaticParams`** روی صفحه‌ی محصول: در زمان build، صفحه‌ی هر محصول از قبل به HTML کامل تبدیل می‌شه.
- ساختار URL خوانا: `/product/p1` (در آینده وقتی محصولات واقعی از دیتابیس اومدن، می‌تونی id رو به یک slug فارسی‌خوان تبدیل کنی، مثلاً `/product/mayeh-vip-tootfarangi`).

## نصب و اجرا

```bash
npm install
npm run dev
```
سایت روی `http://localhost:3000` بالا میاد.

## اجرای نسخه‌ی نهایی (تولید)

```bash
npm run build
npm start
```

## دیپلوی

بهترین گزینه برای Next.js، **Vercel** هست (سازنده‌ی خود Next.js):
1. پروژه رو به یک ریپازیتوری گیت‌هاب پوش کن
2. توی [vercel.com](https://vercel.com) ریپو رو import کن
3. دیپلوی خودکار انجام می‌شه و یه آدرس می‌گیری (بعداً دامنه‌ی `alidadkhah.ir` رو بهش وصل می‌کنی)

## بخش بلاگ و راهنمای خرید

این پروژه یک بخش بلاگ (`/blog`) و یک بخش راهنمای خرید (`/buying-guide`) داره که هر دو از یک جدول واحد در Supabase به اسم `posts` می‌خونن (با فیلد `type` که مقدارش `blog` یا `guide` هست).

### راه‌اندازی (فقط یک‌بار)

1. وارد پنل Supabase پروژه‌ات شو -> **SQL Editor**
2. محتوای فایل `supabase/posts_migration.sql` رو کپی و اجرا کن (جدول `posts` رو می‌سازه، همراه با RLS مناسب)
3. همین. عکس کاور پست‌ها از همون باکت Storage به اسم `product-images` استفاده می‌کنه که احتمالاً از قبل ساختی؛ اگه نساختی، طبق راهنمای فایل `lib/productImages.js` یک باکت عمومی به همین اسم بساز.

### استفاده

- برای مدیریت پست‌ها وارد `/admin` شو، وارد حساب ادمین‌ت بشو، و روی تب **«بلاگ و راهنما»** بزن.
- می‌تونی پست جدید بسازی، نوعش رو (بلاگ یا راهنمای خرید) انتخاب کنی، عنوان/اسلاگ/دسته‌بندی/برچسب/خلاصه/عکس کاور رو تنظیم کنی و متن کامل رو با همون ادیتور غنی محصولات (بولد، تیتر، لیست، هایلایت، درج عکس داخل متن) بنویسی.
- پست‌ها رو می‌تونی «منتشر» یا به‌صورت «پیش‌نویس» نگه داری.
- صفحات عمومی: `/blog` (لیست بلاگ)، `/blog/[slug]` (جزئیات)، `/buying-guide` (لیست راهنما)، `/buying-guide/[slug]` (جزئیات). هر دو صفحه‌ی جزئیات متادیتای سئو اختصاصی و JSON-LD (Article) دارن و به‌صورت خودکار داخل `sitemap.xml` هم قرار می‌گیرن.
- لینک این دو بخش به‌صورت خودکار توی هدر (Navbar) و فوتر سایت اضافه شده.



الان محصولات از فایل `lib/data.js` (دیتای ثابت) میان. وقتی بک‌اند Supabase که قبلاً ساختیم رو وصل کنیم:
- `lib/data.js` رو با `fetch` از `/api/products` جایگزین می‌کنیم
- `generateStaticParams` و `generateMetadata` هم به‌جای آرایه‌ی محلی، از همون API می‌خونن
- چون محصولات ممکنه تغییر کنن، از `revalidate` استفاده می‌کنیم تا صفحات هر چند دقیقه یک‌بار خودکار به‌روز بشن (نه اینکه فقط زمان build بسازه)

## بعد از دیپلوی، این‌ها رو توی Google Search Console انجام بده

1. سایت رو با دامنه‌ی واقعی توی [search.google.com/search-console](https://search.google.com/search-console) اضافه و مالکیتش رو تایید کن
2. آدرس `https://alidadkhah.ir/sitemap.xml` رو submit کن
3. فایل `lib/site.js` رو باز کن و `SITE_URL` رو با دامنه‌ی واقعی جایگزین کن (این مقدار توی sitemap، robots و og:url استفاده می‌شه)
4. سرعت سایت رو با [PageSpeed Insights](https://pagespeed.web.dev) چک کن

## ساختار پروژه

```
app/                    مسیرهای سایت (هر پوشه = یک صفحه)
  layout.jsx            چارچوب کلی + متای پیش‌فرض
  page.jsx               خانه
  shop/page.jsx           فروشگاه
  product/[id]/page.jsx   صفحه‌ی هر محصول (پویا، سئوشده)
  about/, contact/,
  cart/, auth/
  sitemap.js, robots.js   فایل‌های سئوی خودکار
components/             کامپوننت‌های قابل‌استفاده‌ی مجدد
lib/
  data.js                داده‌ی محصولات (فعلاً محلی)
  site.js                تنظیمات کلی سایت (دامنه، نام، توضیحات)
```
